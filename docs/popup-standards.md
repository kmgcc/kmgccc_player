# 弹窗标准

PopupLab 与播放器共用 `Tools/PopupLab/Sources/PopupKit`。Xcode 主 target 只链接本地
`PopupKit` library product，演示 executable、样例与演示面板 presenter 留在 PopupLab 中。
参数定稿保存为 [Standard.json](../Tools/PopupLab/Presets/Standard.json)，默认值定义在
`PopupStyle.swift`。App 通过 `Utilities/AppPopupComponents.swift` 注入唯一 ThemeStore 的语义色；
业务状态、保存、删除和任务生命周期沿用原 owner。

## 默认视觉

| 项目 | 定稿 |
| --- | --- |
| 短表单宽度、圆角、内容留白 | 510 / 15 / 24 pt |
| 标题、正文、正文行距 | 18 / 14 / 6 pt |
| 标题图标、图标与标题间距 | 20 / 18 pt；对齐首行字形中心，多行标题保持相同锚点 |
| 按钮 | 玻璃胶囊；字号 14、最小高 32、最小宽 63、间距 7 pt |
| 操作组外边距 | 上下 13、左右 14 pt；默认靠右 |
| 右上角关闭 | 32 pt，图标 13 pt；上 13、右 14 pt |
| 长内容 | 阅读区默认 384 pt，边缘淡出 9 pt |
| 悬浮动作遮罩 | 向外扩 8 pt，最低不透明度 36% |

这些边距控制整个按钮或按钮组相对弹窗的位置。按钮文字原有内部左右留白只作为预设兼容字段。
常规 App 的强调色跟随 ThemeStore；演示预设的靛蓝只用于独立实验室。全屏按已有尺度等比缩放，
并保留 foregroundProfile 的文字颜色与明暗模式。

按钮标准仅用于窗口右下角操作组与右上角关闭按钮。面板内部的查找、导入、清除、
位置选择与下拉触发按钮使用紧凑的 `AppPanelButtonStyle`，保留各处字号；危险工具按钮
仅以红色文字表示，不染红底面。设置中的皮肤操作使用 12 pt 字号，全屏时沿既有尺度缩放。
全屏 quick panel 属于嵌入设置面板，保留原有标题、分组材质、滚动和关闭控件。外层材质、
强调色与明暗状态直接跟随 MiniPlayer；文字配色从 MiniPlayer 已解析的前景派生，
不再按快速面板所在区域单独切换。清透 / 常规材质设置也同步作用于快速面板。

外层玻璃只渲染一次。选项、说明和输入区使用语义色透明度区分；按钮使用各自的玻璃材质。
封面上方的加载指示器保留小面积磨砂底，以隔开复杂图像。原生控件、popover 箭头和系统窗口
轮廓由 macOS 管理。系统“减少透明度”启用时，共享表面和按钮回退为实色。

| 类别 | 入口 / 内容 | 宿主与布局 |
| --- | --- | --- |
| 简短确认、错误 | 删除、缓存清理确认、维护确认、音效预设读取错误、更新检查错误 | 原有 SwiftUI Alert、confirmationDialog 或 NSAlert；危险动作明确命名 |
| 短表单 | 新建歌单、音效预设命名 | sheet；共享标题、关闭和固定紧凑操作组，名称校验保留 |
| 导入与维护任务 | 批量导入、后台补全、旧缓存清理、资料库补全、音乐偏好重置、导入状态 | 原有 NSPanel / sheet；只读长列表和结果使用悬浮操作组 |
| 资料库向导与重连 | 选择 / 创建资料库、创建播放列表确认、来源选择、重新连接 | 既有 sheet / panel；步骤、选项、固定操作组和原有生命周期保持完整 |
| 阅读 | 普通介绍阅读、全屏介绍阅读、侧栏更新日志 | sheet / 全屏内嵌；共享滚动淡出与悬浮关闭，封面、来源和文字选择保留 |
| 单项详细编辑 | 本地歌曲、外部播放覆盖、艺术家 / 专辑 / 歌单实体 | sheet；550×750 或 560×720，保留完整字段、校验、查找、焦点和固定操作组 |
| 批量编辑工作台 | 歌曲队列、元数据与歌词、预览 | 1120×812 多栏 sheet；共享页眉、关闭和页脚，状态信息可留在按钮左侧 |
| 重复歌曲审查 | 候选组、播放预览、删除确认 | 680×660 sheet；列表淡出，固定完成按钮，原生删除确认 |
| 听感标定 | 片段选择、四阶段调节、结果 | 原有 sheet；共享页眉和紧凑固定操作组，预览恢复与设备切换语义保留 |
| 崩溃反馈 | 操作说明、保存报告、发送 | sheet；共享框架，保留文字限制、导出和 Command-Return 发送 |
| 轻量选择与提示 | 共享选项菜单、输出设备、播放顺序 / 滚轮 / 上报 / Shift 提示 | 原生 popover / NSPopover 或原有内嵌提示；紧凑内容，保留锚点和自动消失 |
| 设置 | 完整设置、全屏快捷外观 | 完整设置保留 NavigationSplitView；快捷外观保留原有嵌入设置布局与材质，不采用弹窗框架 |
| 更新、文件和权限 | WhatsNewKit、Sparkle、Open / Save Panel、fileImporter / fileExporter、系统权限 | 保留组件或系统内容；WhatsNew 的 NSPanel 外层使用共享表面 |
| 拖入提示 | 主窗口内释放以导入 | 原有覆盖层和动效，复用共享玻璃表面 |

7 个业务浮动面板统一经 `AppDialogTokens.makePanel` 构造：资料库设置、批量导入、后台补全、
旧缓存清理、资料库补全、偏好重置、更新说明。factory 提供透明 NSView 宿主，玻璃由 SwiftUI
内容负责；各 presenter 保留层级、父窗口、位置、delegate、retention 和关闭策略。
批量导入仍使用不可原生关闭的窗口，关闭只经原有导入流程。

## 组件用法

- `AppPopupFrame`：普通标题 / 内容 / footer；`onClose` 由业务 owner 提供。
- `AppPopupScrollRegion`：长内容与列表。无 actions 时只有边缘淡出；有 actions 时提供局部悬浮操作。
- `AppPopupActionGroup` / `AppDialogGlassButtonStyle`：窗口右下角操作组的玻璃动作与语义角色。
- `AppPanelButtonStyle`：面板内部工具；紧凑尺寸、局部字号、中性底面和红字危险操作。
- `SettingsTaskDialog`：任务与向导适配。默认固定 footer，`floatsActions` 用于只读执行和结果页。
- `AppDialogHeader` / `AppDialogFooter` / `appPopupSurface`：保留大型工作台布局时复用共享视觉。
- `appPopupContentBackground`：内容分组 / 输入底色，避免在外层玻璃下再叠整块材质。
- `rendersSurface: false`：位于原生 popover 的提示内容，保留系统背景与箭头。

`PopupScrollRegion` 在开头取消上沿淡出，在末尾取消下沿淡出；全部内容可见时两端清晰。
悬浮动作只有自身区域接收点击，其他横向空间继续显示内容。局部遮罩随按钮实际 frame 移动，
并为文末提供滚动余量。交互字段和需要点击的列表采用固定动作，保持末项容易操作。

键盘策略显式定义：普通主要动作可使用 Return，取消 / 关闭可使用 Esc；危险操作不自动取得
Return。运行中的维护任务沿用关闭锁与取消中状态；查看后台进度的“关闭”只关闭报告。
资料库向导的生命周期操作继续由 AppSessionHost 管理，保留其既有关闭许可。
全屏面板保留 FullscreenTransientDismissCoordinator 注册与清理。

## 验收矩阵

| 维度 | 检查 |
| --- | --- |
| 表面 | 浅深色、ThemeStore 主题、复杂封面背景、减少透明度；整层材质与按钮可读性 |
| 标题 | 中文 / 英文、单行 / 多行、subtitle，图标始终对齐首行，右上关闭与标题互不遮挡 |
| 滚动 | 长文本 / 长列表的首、中、尾；短内容无淡出；文末可完全滚过悬浮按钮 |
| 操作布局 | 四边外边距、紧凑按钮、固定 / 悬浮布局；按钮以外的底部仍能显示内容 |
| 表单 | 空白 / 有效名称、Tab 焦点、验证失败重试、保存 / 取消 / 清除覆盖 |
| 任务 | 运行 / 取消中 / 完成 / 失败，忙碌关闭锁、后台报告关闭、重复打开与父窗口焦点 |
| 宿主 | 主窗口、MiniPlayer、皮肤；系统全屏、模拟全屏、主窗口内嵌分别验收 |
| 全屏快捷设置 | 面板打开时切换亮 / 暗封面与清透 / 常规材质，外层与 MiniPlayer 同步；文字和分组随同一明暗状态更新 |
| 原生边界 | popover 锚点 / 箭头 / 外部点击；文件和权限 UI；第三方更新内容 |
