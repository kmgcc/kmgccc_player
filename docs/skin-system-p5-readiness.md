# P5 接续准备

2026-10-05。P5 以原生 P0–P4 的 catalog、包安装、参数、场景宿主与会话为接入点；本文件只冻结接续边界，不宣称 Web 后端已经实现。当前验收与代码修正见 [审查记录](skin-system-review.md)。

## 可直接复用的入口

| 职责 | 现有入口 | P5 接入要求 |
| --- | --- | --- |
| 发现、选择与更新 | `SkinCatalog`、descriptor、运行 revision | Web 定义进入同一列表；同 ID 替换和重载使相关宿主退役旧会话，不新增皮肤 ID 分支 |
| ZIP 与资源 | `SkinPackageStore`、`PackagedSkin.origin` | 复用暂存/验证/发布和失败保留旧安装；HTML/ESM 的资源加载限定在对应安装根目录 |
| 参数 | `SkinParameterDefinition`、`SkinParameterStore` | 普通用户仍只看到作者标记的重要参数；按现有类型、范围和选项兼容规则解析 |
| 可用视口 | `SkinViewport` | 传逻辑点尺寸、显示比例、宿主角色和裁剪语义；不能把旧设计画布当作实际窗口 |
| 稳定数据 | `SkinSceneSnapshot` | 将当前字段映射成可序列化、带 revision 的消息；不把 Swift 对象或整个领域服务暴露给脚本 |
| 实时数据 | playback/lyrics/audio readers | 时钟用锚点和 seek/play/pause 校正；音频只送共享分析帧，明确外部来源没有真实 PCM |
| 操作 | `SkinSceneActions` | 播放、队列、喜欢和界面动作继续调用已有 owner；校验 action 与参数，不提供任意方法调用 |
| 卸载与资源 | `SkinSession`、组件局部清理 | 每个 Web 实例登记 disposer；隐藏/重载/退出停止从属工作，晚到消息检查实例 generation |
| 必要恢复入口 | `SkinSceneControlHost` | App 独立退出与恢复始终可达；脚本声明的按钮不能吞掉 App 的恢复能力 |

原生 v1 Schema 继续描述已登记的原生组件，不提前塞入未实现的 Web 字段。包格式版本、宿主 API 版本和作者版本继续分开；未知必需后端明确拒绝，不自动换成原生效果。

## 实施顺序

1. 在 `AppSessionHost` 组合一个有限的 Web 数据/动作适配，定义版本化的静态更新、时钟、分析帧与动作消息。先写清时间单位、歌词偏移和封面资源身份。
2. 加入包内 HTML/CSS/ESM 的运行实例，负责 prepare、mount、可见性、更新和 dispose；与已有 AMLL 背景共享经验，保留原背景适配。
3. 交付 Web 背景与原生歌词组合样例，验证透明层、点击、拖动、Retina 和缩放。原生歌词仍仅由现有 manager 持有。
4. 交付显式 Web 歌词效果，使用同一歌词文档/时间语义；不另造匹配或获取服务。然后按批准范围接完整 Web 排版与自绘控制。
5. 使用现有本地导入、重载和删除路径验收切歌、pause/seek、错误、隐藏与退出；Web 内容进程和订阅回到同一基线后，再进入 P6 开发目录与预览。

验收首先用真实 App 与本地 ZIP。桥接契约回归用于定位错误；构建成功不能替代 WebKit 行为与画面确认。

## P5 开始时集中确认

- D08：首版开放 Web 背景 + 原生节点，以及完整 Web 场景的具体组合范围。
- D06/D16：App 独立退出/恢复入口的外观与 Web 输入边界；全局快捷键继续归 App。
- D13：仅包内资源或允许网络，以及外部链接的打开方式。
- D19：脚本重载后的临时状态与动画时间恢复；原生 P4 的重建状态不构成 Web 状态序列化承诺。

这些决定属于新增 Web 行为，不阻挡现有原生 ZIP 使用。Folium 兼容在 P7 按目标版本与样例逐项验证，市场与点击在线更新仍归 P9。

## 继续维护的边界

`FullscreenPlayerView` 仍承载旧预设的主题与恢复时序。新增 Web 生命周期放在运行实例与会话，不往这个文件叠加后端分类布尔值。现有内置外观继续走旧适配；更细的预设部件、独立 SDK、字体/视频支持和历史版本管理由实际作者样例推动，分别验收。
