# DSP 处理负载

音效设置中的节点卡片以绿色、黄色、橙色、红色连续表达处理负载。
只有效果链标题旁显示负载百分比。普通音效、脚本与固定的等响补偿共用同一套测量和呈现。

## 指标口径

负载 = 实际处理耗时 / 对应源音频的播放时长。

例如，处理 2048 帧、48 kHz 音频耗时 1.28 ms，对应负载为 3%。
耗时使用单调时钟，线程被抢占的时间也会计入。它描述当前机器、音频格式和参数下的
处理成本，不等同于 App CPU 百分比，也不能单独推导出音频断续的概率。

- 节点耗时包住整个节点的音频块处理，包括该节点必要的前瞻计算；源音频时长只计一次。
- 整链耗时包住整个 DSP `process`，包括输入/输出转换、增益、前瞻状态复制和延迟补偿。
  解码、获取未来 PCM、renderer 入队和音频设备延迟不属于此指标。
- 配置切换的预热、历史重算、旧链/新链交叉淡化不进入日常负载。
- 平均值按抽样块的音频时长加权，并用约一秒时间常数平滑。悬停信息中的“近期抽样峰值”
  是上一次发布以来采到的最高比例，抽样可能漏过瞬时尖峰。
- 报告保留超过 100% 的值，只有颜色在红色处饱和。全部数值为临时状态，不写入预设或磁盘。

## 颜色与无数据状态

颜色经 `SemanticPalette` 提供绿、黄、橙、红的负载语义色，再与现有卡片底色轻量混合。浅、深色分别使用固定的感知亮度和饱和度，深色降低饱和度和混合强度；色阶经统一颜色适配层渲染，每种外观只生成一次。
字体、卡片形状、控件位置和拖动浮层保持原有结构。文字数值与 VoiceOver 提供颜色之外的读法。
节点折叠时整卡轻量着色；展开时进一步降低颜色强度，只保留标题区域的浅色。标题末端开始柔化，下方仅延伸 10 点，以逐渐减弱的短尾恢复正常编辑区底色。
渐变按固定标题高度绘制，不随编辑区高度拉伸，也不使用模糊、离屏遮罩或额外的布局测量。

| 对象 | 绿色起点 | 黄色 | 橙色 | 红色 |
| --- | --- | --- | --- | --- |
| 单节点 | 0% | 5% | 15% | 30% |
| 整链 | 0% | 25% | 50% | 80% |

各段之间连续插值。这些是固定的处理预算参考线，不按链内排名归一化；单节点的红色表示
它占用较多预算，整链的红色表示留给解码、调度等其他工作的余量较少。参考线属于显示策略，
尚需真实播放和性能采样校准，不是经过设备测量确定的断续门槛。

有效的零混合量、零增强量和恒等节点会被音频处理器跳过，其节点成本为零，呈现为轻负载。
这种状态和参数、格式不支持导致的缺测分别处理，统计不会为了测量而强行执行直通音效。
关闭的节点与其他设备的音效链保持中性底色。暂停、开关、调参、载入/跳转、输出设备变化和
采集间断保留上次结果；新数据到达后更新，不使用过期清空计时器。整链开关关闭时也保留上次百分比。
新快照按节点 ID 合并，暂时关闭的节点保留自己的结果，已经移出当前配置的节点从缓存移除。
资料库 session 或播放来源更换明确清除上一条链的数据；旧请求、旧播放时间线和旧可见会话的报告仍被拒绝。

## 开销控制

- 只在至少一个设置视图查看当前播放设备的效果链时启用。离开后关闭采集；多个窗口独立登记。
- 处理器稳定执行约 0.125 秒音频后才建立采集器，避免连续调参时反复建立统计数组。
- 此后每约 0.125 秒源音频抽测一块，实际频率随块长向下取整，约每秒音频最多八块。
- 每个被抽测的节点调用前后各读一次时钟；前瞻另计一对。逐采样循环不增加计时。
- 采集器限定在现有 producer queue，使用固定数组，采样阶段不加锁、不分配字典、不发送回调。
- 至少相隔 0.5 秒且有新样本时才构造展示快照；只有数值标签和背景子视图订阅快照，
  测量刷新不会重新计算 EQ 曲线或节点拖动几何。结果缓存不设置计时器，采集器重建不发送清空消息。
- 隐藏时不读取性能时钟，保留的额外工作仅为音频块/节点层的条件判断。

以上是代码层面的开销控制，实际 CPU 和计时扰动需要同一 Release 产物、固定输入的 A/B 测量确认。

## 验收路径

回归用例收录在已有 test target 的 `AudioDSPProcessorTests.swift` 和 `AudioDSPControllerTests.swift`：
PCM/递归状态一致性、旁路无样本、前瞻归并、时长加权、抽样频率、发布节流、平滑与峰值、
多个设置窗口、配置/session/可见会话隔离、外部来源、末次结果保留、零成本直通节点和缓存裁剪。

人工检查矩阵：

| 路径 | 检查点 |
| --- | --- |
| EQ、虚拟低音、电子管、脚本、等响补偿 | 节点以颜色呈现，只有整链显示百分比；直通音效为轻负载 |
| 44.1/48/96/192 kHz、多声道、短末块 | 比例按实际音频时长计算，格式切换后保留上次结果直到新测量 |
| 节点开关、整链开关、失败旁路 | 停测期间保留结果，开启后恢复已有颜色，再接受新结果；错误仍由诊断呈现 |
| 播放/暂停/恢复、停止、跳转、曲目结束 | 不闪回空数据，恢复采集后更新测量 |
| 输出设备、其他设备预设、本地/外部来源、资料库切换 | 报告只归属于当前有效播放链 |
| 拖动、展开编辑、多个设置窗口、浅/深色、Reduce Motion、VoiceOver | 展开卡片只有顶部压力色和短渐变，布局稳定，采集生命周期正确 |
| 设置可见/关闭的 Release 对照 | 固定输入下比较 CPU、线程调度和界面刷新开销 |

上述运行验收遵循仓库的构建、测试和主 App 启动授权规则。
