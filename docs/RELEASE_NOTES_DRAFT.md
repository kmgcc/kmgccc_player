## v2.3.0 · 2026-09-03

### 新增

- **空间音频**：支持 macOS 系统级空间音频与头部跟踪。
- **蓝牙自适应延迟**：针对蓝牙等音频设备自动调整延迟，使动效与声音更同步。
- **多资料库与目录引用**：可管理多个独立曲库，并支持直接使用本地既有文件夹，无需导入或搬移歌曲文件。
- **资料库进阶功能**：补充文件链接管理和更多资料库统计选项，修复了列表排序记忆丢失的问题。
- **专辑与艺人长文阅读**：点击介绍可打开大窗口阅读完整内容；全屏播放器右键菜单新增"查看详情"快捷入口。
- **全屏滚轮调音**：全屏模式下，所有皮肤均支持在封面区域滑动滚轮调节音量。
- **HDR 点缀**：新增 HDR 开关，在受支持的 XDR 屏幕上以更高动态范围显示 LED 仪表。
- **歌词高刷显示（实验性）**：尝试支持歌词的高刷新率渲染，受 Safari WebView 限制，目前仍在调试中，效果尚不稳定。

### 优化与修复

- 修复音频分析管线在切歌或停止播放时可能引起的偶发闪退。
- 优化封面与歌词加载流程，减轻主线程负担，切歌更流畅。
- 优化内存管理，在系统内存紧张时自动释放缓存。
- 优化检查更新流程，改进当前已是最新版本时的提示效果。
