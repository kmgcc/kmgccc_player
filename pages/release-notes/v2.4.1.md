## [v2.4.1] - 2026-10-21
### Added

- **音效✨**：新增均衡器、低音增强、混响等音效，可以调整顺序，并为不同设备保存设置。
- **音量均衡**：统一不同歌曲间的音量，采用统一放缩，不会引入压缩失真。
- **拖动歌曲**：可把多首歌曲拖进歌单或播放队列，也可拖到专辑、艺人页面整理。
- **歌词导入（beta）**：可手动为歌曲导入更多格式的歌词；导入歌曲时，也会自动寻找同名歌词文件。
- **后台任务与存储空间**：可查看后台任务的进度、资料库占用的空间，并分类清理缓存。

### Improved

- **界面**：增加三种配色选择，调整主页卡片浏览和全屏布局。
- 切歌时提前准备封面和歌词，并改善声音与频谱同步。
- 已连接的 MCP agent 可调整音效并管理后台任务。

### Fixed

- 修复资料库读取出错时歌曲信息被误删，以及整理歌曲保存失败后内容未恢复的问题。
- 修复导入时无法选择文件夹、输入框方向键触发快进的问题。
- 修复外部歌曲信息保存失败仍关闭窗口和部分背景切换异常的问题。

### Files

DMG 为安装包；`.symbols.zip` 用于崩溃报告符号化，日常使用无需下载；`.sha256` 为安装包和符号包的校验文件。
