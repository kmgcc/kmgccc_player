## [v2.4.1] - 2026-10-21

### Added

- **音效✨**：新增均衡器、低音增强、混响等音效，可以调整顺序，并为不同设备保存设置。
- **音量均衡**：统一不同歌曲间的音量，采用统一放缩，不会引入压缩失真。
- **拖动歌曲**：可把多首歌曲拖进歌单或播放队列，也可拖到专辑、艺人页面整理。
- **歌词导入（beta）**：可手动为歌曲导入更多格式的歌词；导入歌曲时，也会自动寻找同名歌词文件。
- **后台任务与存储空间**：可查看后台任务的进度、资料库占用的空间，并分类清理缓存。

### Changed

- **界面**：配色改为三种选择；主页卡片可以用鼠标拖动浏览，全屏和弹窗的布局也作了调整。
- **切歌**：提前准备下一首歌的封面和歌词，并调整声音与频谱画面的同步。
- **MCP**：已连接的 agent 可以调整音效，查看和管理后台任务。

### Fixed

- 修复资料库读取出错时，可能误删歌曲信息的问题；拖动整理歌曲保存失败时，也会恢复原来的内容。
- 修复导入时无法选择文件夹，以及在输入框里按方向键却触发快进的问题。
- 修复编辑其他播放器的歌曲信息时，保存失败却仍关闭窗口的问题，以及部分背景切换异常。

### 安装与校验

支持 macOS 26.0 及以上，仅支持 Apple Silicon。打开 DMG，将 kmgccc_player 拖入 Applications 后启动。App 与 DMG 已使用 Developer ID 签名并通过 Apple 公证。

DMG 为安装包；`.symbols.zip` 用于崩溃报告符号化，日常使用无需下载；`.sha256` 为安装包和符号包的校验文件。将待校验文件放在同一目录后运行：

```sh
shasum -a 256 -c kmgccc_player_2.4.1_16.sha256
```
