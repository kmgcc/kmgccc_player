### 安装与校验

支持 macOS 26.0 及以上，仅支持 Apple Silicon。打开 DMG，将 kmgccc_player 拖入 Applications 后启动。App 与 DMG 已使用 Developer ID 签名并通过 Apple 公证。

DMG 为安装包；`.symbols.zip` 用于崩溃报告符号化，日常使用无需下载；`.sha256` 为安装包和符号包的校验文件。将待校验文件放在同一目录后运行：

```sh
shasum -a 256 -c kmgccc_player_2.4.4_20.sha256
```
