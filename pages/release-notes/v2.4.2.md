## [v2.4.2] - 2026-10-26

### Added

- **✨Apple Music 动态封面**：可为歌曲或专辑查找动态封面，也可以使用自己的视频。
- **侧边栏快捷按钮**：可以挑选和排列按钮，最多放四个。
- **自定义工具栏**：可以按使用习惯自定义工具栏。

### Changed

- **设置布局**：重新整理设置项并按功能分组。
- **切歌**：封面显示衔接得更快。

### Fixed

- 保存封面时尽量保留原图，减少图片变小或变糊的情况。
- **旧封面更新**：旧版本可能降低了部分封面的画质；App 会为这些歌曲重新查找更清晰的封面。任务可以暂停或结束。旧曲库中来源不明的封面可能会被替换。若要保留手动换过的封面，请在 App 启动后停止此任务。
- 自动补充歌曲资料时保留手动修改，避免被自动结果覆盖。

### 安装与校验

支持 macOS 26.0 及以上，仅支持 Apple Silicon。打开 DMG，将 kmgccc_player 拖入 Applications 后启动。App 与 DMG 已使用 Developer ID 签名并通过 Apple 公证。

DMG 为安装包；`.symbols.zip` 用于崩溃报告符号化，日常使用无需下载；`.sha256` 为安装包和符号包的校验文件。将待校验文件放在同一目录后运行：

```sh
shasum -a 256 -c kmgccc_player_2.4.2_18.sha256
```
